🔔 Alertes email

Les alertes par email (changement de signal d'un onglet) sont envoyées par le serveur de données, pas par ce navigateur. Elles se configurent dans GitHub : Settings → Secrets and variables → Actions du dépôt marketsensor-backend.

SMTP_USER votre@gmail.com
SMTP_PASSWORD mot-de-passe-application-Google
ALERT_EMAILS destinataire@email.com

Dans ce navigateur, étoilez des indicateurs (☆) : un message s'affiche (et une notification si vous l'autorisez) quand leur signal change, à la prochaine ouverture de la page.
